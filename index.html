Google Apps Script Code Instructions

Copy the Google Apps Script code below and paste it into your Google Spreadsheet's Script Editor to enable multi-device sync across all 45 branches. 

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var cellValue = sheet.getRange("A1").getValue();
  var data = {};
  if (cellValue) {
    try {
      data = JSON.parse(cellValue);
    } catch(err) {
      data = {};
    }
  }
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var contents = e.postData.contents;
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    sheet.getRange("A1").setValue(contents);
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Quick Setup Steps:

  1. Open a new blank sheet on Google Sheets.
  2. In top menu, click Extensions > Apps Script.
  3. Delete all default text in Code.gs and paste the code above.
  4. Click Deploy > New Deployment.
  5. Click the Gear Icon (Select type) and pick Web app.
  6. Set Execute as to "Me" and Who has access to "Anyone".
  7. Click Deploy, authorize permissions, and copy the generated Web App URL.
  8. Paste that Web App URL in the Settings modal of this app!
